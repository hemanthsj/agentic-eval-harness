# agentic-eval-harness
Build a system that generates synthetic outbound messages, runs them through an LLM-judge against a rubric (disclosures, opt-out language, jurisdiction rules), and reports pass/fail with reasoning traces. Hits your Hamel/Shreya evals interest head-on, uses your actual domain, and "how I built an LLM-judge I actually trust" is a strong blog arc.
